# Лични забележки за c++ и задачите

### Променливи 
За разлика от python, даже за 2 разлики - в c++ има задължителни типове (в python също активно ползвам типизирането, тъй като в големи проекти няма шанс без типове. Кратно намалява грешки!) и, има примитивни типове на променливи. Те са доста, но интересно че има тип auto за автоматично определяне на тип променлива от присвояване

### Символи и строкове

##### Масиви като строкове
В c-подобни езики най-често няма вграден тип за строка като "Hello world" - ще трябва да ги съхраняваме в динамични масиви char m[]={"string"}. Може и в многомерни масиви за много строкове съответно.
```
#include <iostream>
using namespace::std;

int main() {
    const int num_char = {100} //да е 100 символа за една строка
    string text[][num_char] = {"Python", "ruby", "go"};

}
```
тука ще можем да въведем колкото да не е при инициализацията строкове с ограничена дължина 100.

##### Тип std::string
Тип за строкове, който е малко по-удобен от същия на масиви, обаче пак както инициализираме променлива ще трябва да сложим един динамичен масив, с нулево значение.
нещо подобно:
```
#include <iostream>
using namespace::std;

int main() {
    string text[] = {};
    cout << "input your string WITHOT SPACES!" <<"\n";
    cin >> &text;
}
```
доста прост код - единственно че за разлика от динамичен масив като въвеждаме то ще спре с space от клавиатура. Няма да го поеме като символ

### array + pointer
Поинтери като цяло - са доста интересна концепция, към която не съм свикнал много. Обаче не е много трудно - осоьено интересно става с масиви. Оказва се че целия масив е pointer, pointer на негов първи елемент. Кода представен по-низо го доказва с практика:

```
#include <iostream>
using namespace::std;

int main() {
    int masiv[2] = {1, 2};
    cout << masiv[0] << "\n";
    cout << masiv << "\n";
    cout << *masiv << "\n";
}

```

### локални / глобални променливи
Не ми е учудваща тази конструкция, единствено интересно че локални променливи прекриват по-глобални, което е нормално за доста езици. И мога да взема глобална променлива като използвам namespace: ```::променлива```

### Доступ към оригиналния аргумент с поинтери

ако ще предам в функция като аргумент поинтер, а не самата променлива - ще получа копие на поинтера в тяло на функция, както и копие на прост аргумент. Иначе копие на поинтер сочи към същото място в паметта както и оригинала, така че можем да получим достъп към оригинална променлива.

### Разликита помежду " и '
Се е оказало че помежду ' и " има голяма разлика, тъй като '' е само char а "" е масив const char* - ["\0"] е минимално за края на масива за строка.
